Laboratoire 1 : Configuration d'un réseau local simple (LAN)

Objectifs :
  • Créer un réseau local de 3 ordinateurs interconnectés par un commutateur (Switch).
  • Configurer les adresses IPv4 statiques et les masques de sous-réseau.
  • Vérifier la connectivité locale avec la commande ping.

📌 Les noms affichés dans les captures d'écran

Packet Tracer numérote automatiquement chaque appareil ajouté : PC7, Switch3, Router1… Ce numéro dépend simplement du nombre d'appareils déjà créés depuis l'ouverture du logiciel. Vos numéros seront différents des miens, et c'est parfaitement normal.

Fiez-vous toujours à l'adresse IP et à la position dans la topologie — jamais au nom affiché. Correspondance dans ce guide :

  • PC7, PC8, PC9 = les trois postes du Réseau A (192.168.1.10 à 192.168.1.12). Celui qui porte 192.168.1.10 est le PC1 de l'énoncé.
  • PC10, PC11 = les deux postes du Réseau B (192.168.2.10 et 192.168.2.11), soit PC4 et PC5.
  • Switch3 = Switch 1 (Réseau A)  ·  Switch4 = Switch 2 (Réseau B)  ·  Router1 ou Router3 = le Routeur.

Attention aussi à l'orientation : dans les captures, le Réseau A apparaît à droite et le Réseau B à gauche. La position à l'écran n'a aucune importance — seul l'adressage compte. Vous pouvez renommer un appareil en cliquant sur son nom, sous l'icône.

Étape 1 : Ajout des équipements

  1. En bas à gauche, cliquez sur l'icône End Devices (Flèche 1).
  2. Dans le panneau de droite, sélectionnez PC (Flèche 2) et faites un glisser-déplacer de 3 ordinateurs (PC1, PC2, PC3) dans la zone de travail.
  3. En bas à gauche, cliquez sur Network Devices (Flèche 1), puis sur Switches (Flèche 2).
  4. Choisissez le modèle 2960 (Flèche 3) et glissez-le vers le centre de l'écran pour former le Switch 1.

🔌 Qu'est-ce qu'un Switch (Commutateur) ?

Un Switch sert à interconnecter des machines appartenant à un même réseau local (LAN). Il apprend dynamiquement les adresses MAC des appareils connectés à ses ports et distribue intelligemment les messages uniquement vers le bon destinataire local.

Étape 2 : Câblage des équipements

  1. Cliquez sur l'icône en forme d'éclair Connections (Flèche 1).
  2. Sélectionnez l'éclair orange Automatically Choose Connection Type (Flèche 2).
  3. Reliez chaque PC au Switch 1 un par un (cliquez sur le PC, puis sur le Switch).

Étape 3 : Configuration des adresses IPv4

  1. Double-cliquez sur le premier PC (PC1).
  2. Dans la fenêtre qui s'ouvre, allez dans l'onglet Desktop (Flèche 1), puis cliquez sur IP Configuration (Flèche 2).
  3. Entrez les paramètres suivants :
    • IPv4 Address : 192.168.1.10
    • Subnet Mask : Cliquez dans la case, il se remplit automatiquement à 255.255.255.0.
  4. Répétez l'opération pour les deux autres PC du Réseau A :
    • PC2 : IP 192.168.1.11 | Masque 255.255.255.0
    • PC3 : IP 192.168.1.12 | Masque 255.255.255.0

Étape 4 : Vérification et tests de connectivité

  1. Double-cliquez sur PC1 (192.168.1.10).
  2. Dans l'onglet Desktop, ouvrez Command Prompt.
  3. Tapez ipconfig pour vérifier vos paramètres, puis testez la communication avec PC2 :
    C:\> ping 192.168.1.11
    (Vous devez obtenir 4 réponses "Reply from 192.168.1.11").

Laboratoire 2 : Interconnexion de deux réseaux via un Routeur (Passerelle)

RÉSEAU A
192.168.1.0
  • • PC1 : 192.168.1.10
  • • PC2 : 192.168.1.11
  • • PC3 : 192.168.1.12
  • • Switch 1 (2960)
◄─►
ROUTEUR (ISR4331)
Gig0/0/0 : 192.168.1.1
Gig0/0/1 : 192.168.2.1
◄─►
RÉSEAU B
192.168.2.0
  • • PC4 : 192.168.2.10
  • • PC5 : 192.168.2.11
  • • Switch 2 (2960)

Étape 1 : Créer le Réseau B

  1. Ajoutez un 2ᵉ Switch (Switch 2) et 2 nouveaux PC (PC4 et PC5).
  2. Câblez ces PC au Switch 2 avec l'éclair orange.
  3. Configurez les adresses IP statiques du Réseau B :
    • PC4 : IP 192.168.2.10 | Masque 255.255.255.0
    • PC5 : IP 192.168.2.11 | Masque 255.255.255.0

Étape 2 : Ajouter le Routeur (La Passerelle)

🌐 Qu'est-ce qu'un Routeur (Passerelle / Gateway) ?

Contrairement au Switch qui travaille uniquement à l'intérieur d'un même réseau, le Routeur possède des interfaces dans plusieurs réseaux distincts. Son rôle est de transférer les paquets de données d'un réseau IP vers un autre. L'adresse IP du routeur dans votre sous-réseau est ce qu'on appelle la passerelle par défaut (Default Gateway).

  1. Sous Network Devices > Routers, choisissez le routeur ISR4331 et glissez-le entre les deux Switches.
  2. Avec l'icône Éclair orange :
    • Câblez le Switch 1 au Routeur (interface GigabitEthernet0/0/0).
    • Câblez le Switch 2 au Routeur (interface GigabitEthernet0/0/1).
    (Remarque : Les voyants restent rouges car les interfaces d'un routeur Cisco sont éteintes par défaut).

Étape 3 : Configurer les interfaces du Routeur (Les Passerelles)

  1. Double-cliquez sur le Routeur > onglet Config.
  2. Interface Réseau A (Côté gauche) : Cliquez sur GigabitEthernet0/0/0, entrez l'IP 192.168.1.1, Masque 255.255.255.0, et cochez Port Status : On.
  3. Interface Réseau B (Côté droit) : Cliquez sur GigabitEthernet0/0/1, entrez l'IP 192.168.2.1, Masque 255.255.255.0, et cochez Port Status : On.

Étape 4 : Indiquer la Passerelle aux PC

  1. Sur le Réseau A, ouvrez la fenêtre IP Configuration de chaque poste (PC1, PC2, PC3).
  2. Renseignez le champ Default Gateway avec l'adresse du routeur côté gauche : 192.168.1.1.
  3. Sur le Réseau B, renseignez la Default Gateway de chaque PC (PC4, PC5) avec l'adresse côté droit : 192.168.2.1.

Étape 5 : Le Grand Test de Routage !

  1. Ouvrez l'invite de commande de PC1 (192.168.1.10).
  2. Testez la joignabilité de sa propre passerelle : ping 192.168.1.1
  3. Testez la communication inter-réseau vers PC4 du Réseau B : ping 192.168.2.10
    (Le premier paquet peut indiquer "Request timed out" le temps que la table ARP se construise, puis les suivants répondent avec succès !)

🎯 Étape 6 : Prouver l'utilité absolue de la passerelle

Cassez volontairement la configuration, puis observez

Vous venez de faire communiquer deux réseaux. Vérifions maintenant ce qui rendait cette communication possible.

  1. Sur PC1 (192.168.1.10), retournez dans IP Configuration et effacez l'adresse de la Default Gateway (remettez-la à 0.0.0.0). Ne touchez à rien d'autre : l'adresse IP, le masque et les câbles restent exactement les mêmes.
  2. Ouvrez le Command Prompt et relancez le ping vers PC4, qui se trouve dans l'autre réseau :
    C:\> ping 192.168.2.10
    Résultat immédiat : Destination host unreachable.
  3. Relancez maintenant un ping vers PC2, qui est dans votre propre réseau :
    C:\> ping 192.168.1.11
    Celui-là fonctionne toujours.
  4. Remettez la passerelle 192.168.1.1 sur PC1 et vérifiez que le ping vers PC4 repasse.

Ce qu'il faut comprendre : sans l'adresse de sa passerelle, le poste ne sait pas à qui remettre un paquet destiné à un autre réseau — il ne l'envoie même pas sur le câble. En revanche, les machines de son propre réseau restent parfaitement joignables. La passerelle ne sert qu'à sortir du réseau local.
